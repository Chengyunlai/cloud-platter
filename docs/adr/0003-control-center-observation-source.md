# ADR-0003：使用系统媒体卡片作为 MVP 播放状态源

- 状态：已替代
- 日期：2026-08-04
- 替代：ADR-0001 中由 MediaRemote 读取完整元数据的部分
- 被替代：[ADR-0004](0004-isolated-mediaremote-adapter.md)

## 背景

macOS 26.3 和网易云音乐 3.1.9 的现场验证表明，网易云音乐已经把当前媒体发布给系统，
控制中心能够显示曲名、艺人、封面和播放按钮。普通进程也能通过 MediaRemote 确认当前
播放器路径属于 `com.netease.163music`，但旧式全局查询、local/active/path origin 查询和
客户端枚举均无法取得元数据。

通过 `MRNowPlayingRequest` 显式请求元数据时，`mediaremoted` 将请求正确路由到网易云，
但返回 `kMRMediaRemoteFrameworkErrorDomain / 3 / Operation not permitted`。系统二进制
包含 `com.apple.mediaremote.now-playing-read-access` 等私有 entitlement；把最小读取
entitlement 写入 ad-hoc 签名后，签名本身有效，但应用被 AMFI 终止，退出码为 137。
因此，普通 GitHub 自签构建不能把 MediaRemote 作为完整元数据来源。

Accessibility Spike 得到以下结果：

- 网易云自身的 CEF 主窗口不导出内容辅助功能树，手动与增强辅助功能开关均不可用。
- 控制中心展开时存在稳定的媒体分组：一个富文本节点、三个按钮和一个图像节点。
- 富文本按标题、单字符分隔、艺人形成三个样式区间，可以不读取具体内容地稳定拆分。
- 播放或暂停状态可以从按钮语义识别。
- 图像节点不提供 URL 或像素；获得真实封面需要 ScreenCaptureKit。
- ScreenCaptureKit 能在内存中捕获可见控制中心窗口并裁出 81×81 封面；离屏窗口捕获
  返回 `SCStreamErrorInternalError`。
- 控制中心窗口可以临时移到屏幕外，移动期间文本、按钮和图像 AX 节点仍然可读，关闭
  后节点失效。探针曾观察到离屏富文本长度变化，但用户随后确认当时没有手动切歌；进一步
  验证还发现媒体卡片展开后会异步替换或补全文本节点。因此该变化只能证明 AX 内容可能
  更新，不能作为手动切歌验证。控制中心也可能自动关闭，长期观察能力尚未确认。

## 决策

- 保留 Swift、AppKit、SwiftUI 和 Core Animation 技术栈。
- 用可替换的 Playback Observation Source 取代“完整 MediaRemote 适配器”这一接口假设。
- MVP 默认通过 Accessibility 读取 macOS 控制中心的系统媒体卡片。
- 标题和艺人按富文本样式区间解析；播放状态按按钮语义解析，不依赖本地化后的具体文案。
- 真实封面是可选能力：获得屏幕录制权限后，通过 ScreenCaptureKit 在内存中捕获并只裁剪
  AX 图像范围；权限缺失或捕获失败时使用默认唱片。
- 采样必须恢复控制中心原有位置和开关状态，不得长期遮挡界面。真实封面只在窗口可见时
  采样，后续切歌捕获必须限制频率并明确记录可能短暂展开系统界面的体验限制。离屏文本
  观察仍需解决初始化异步更新、控制中心自动关闭和重新定位节点问题，未验证前不得作为
  MVP 的持续数据通道承诺。
- MediaRemote 只保留为运行时来源识别或变化信号的候选后端，不读取或记录完整媒体内容。
- 所有原始系统对象继续隔离在数据源边界；UI 只消费规范化 Now Playing State。

## 后果

- GitHub 自签构建不依赖 Apple 私有 entitlement，也不要求用户关闭 SIP 或 AMFI。
- 首次使用需要辅助功能权限；启用真实封面还需要屏幕录制权限。
- 系统媒体卡片的结构和布局可能随 macOS 更新，需要匿名结构 fixtures 与兼容矩阵。
- 控制中心会自动关闭，且展开初期可能异步替换 AX 节点；适配器需要稳定基线、失效检测
  和重新定位策略。若无法在不打扰用户的前提下持续观察，MVP 需改为按需刷新或重新评估
  数据源。
- 封面捕获只提供系统卡片当前渲染的分辨率，不能保证原始专辑封面质量。
- 无权限、卡片不存在或结构变化时，应用必须无崩溃进入不可用或默认封面状态。

## 替代方案

- 私有 MediaRemote entitlement：普通 ad-hoc 构建会被 AMFI 终止，不适用于直接分发。
- 关闭 SIP/AMFI：安全代价过高，不作为项目安装路径。
- 读取网易云 CEF 辅助功能树：当前客户端主窗口没有导出内容节点。
- 社区 API、本地 Cookie、进程注入：超出隐私与产品边界。
- 只显示默认封面：可作为无屏幕录制权限时的安全降级，但不作为完整体验。
