| 场景 | 结果 | 匿名证据 |

| 普通歌曲一次性快照 | 通过 | 用户确认内容类型；来源为 `com.netease.163music`，标题、艺人、专辑、时长、进度和封面存在 |

| 恢复播放 | 通过 | 自动发送播放后实时流更新为 `playing=true` |
| 切歌 | 通过 | 自动发送下一首后标题、艺人和专辑匿名长度变化，最终状态稳定为播放 |
| 进度拖动 | 通过 | 从 0 秒定位到 5 秒，随后快照读取到 5 秒 |

| 网易云客户端重启 | 通过 | 退出后不保留旧状态；重新启动并播放后 2 秒恢复来源与完整文本字段 |
| CloudPlatter 正常退出 | 通过 | App、supervisor 和 Perl helper 全部退出 |

切歌期间观察到网易云会发送若干短暂的播放/暂停过渡和中间元数据，最终会收敛到稳定的新
曲目。默认适配器使用 100 毫秒 debounce；主应用必须继续按事件顺序合并 diff，不能把中间
状态写入日志或持久化。
