# v0.1.0 稳定版验收范围

本轮先发布维护预览版 `v0.1.0-preview.4`。稳定版只承诺经过实机验收的组合；Universal 构建成功不等于 Intel 或全部 macOS 版本已验证。

## 需要完成的有限清单

| 项目 | 操作与通过标准 | 当前证据 |
| --- | --- | --- |
| 状态一致性 | 播放、暂停、连续切歌、缺少封面、来源切换；封套、唱片中心、标题对应同一状态，不向其他播放器发命令 | 匿名回归与本机按钮通过；连续切歌 / 来源切换实机收口留在 #7 |
| 生命周期 | 同一支持环境：客户端重启一次；锁屏 / 解锁、系统休眠 / 唤醒各一次；切换音频输出一次；恢复后状态正确且无需重启应用 | 客户端重启有历史记录；本轮其余实机操作待验证 |
| 桌面显示 | 单屏隐藏 / 恢复、重启保留；切换 Space、进入 / 退出全屏；若宣称支持多屏，实际接入 / 移除一次、改变分辨率并检查控制层与偏好 | 单屏设置与持久化通过；多屏、Spaces、全屏待验证 |
| 持续资源 | 空闲、播放、暂停、隐藏各固定状态采样 10 分钟，覆盖主进程与 helper；连续运行 60 分钟检查内存增长；播放 / 隐藏各记录 GPU 活动 | 短时主进程与混合会话进程树样本只能作观察，不能替代此项 |
| 隐私与故障 | 检查默认日志与诊断输出；缺失 helper、超时、取消、主流恢复不泄露媒体、不遗留调用、不崩溃 | 自动化进程与状态回归通过，发布包默认日志核查待完成 |
| 安装 | 发布 DMG / ZIP 校验，未装过的新用户环境执行首次打开；核对 Gatekeeper 说明和回退步骤 | Universal 本地打包通过；公开包校验在发布时执行，新用户验收待完成 |

资源验收需要记录采样条件与曲线；不预设没有证据的 CPU 百分比承诺。发现持续增长、隐藏后仍有持续渲染或进程泄漏，先定位并修复，再发布稳定版。系统媒体查询仍可在隐藏时运行，应与渲染成本分开解释。

## 支持范围与探索范围

首个稳定版先收口 macOS 26.3 / 网易云音乐 3.1.9 / Apple Silicon；最低部署目标仍为 macOS 14。其他系统、Intel 实机、Stage Manager、不同内容类型按反馈扩展，未经验证时明确标注待验证。若某环境无法验收，缩小正式支持声明，不能把未验收项目勾成已完成。

## 手动匿名资源采样

```bash
python3 scripts/sample-process-tree.py --pid <CloudPlatter主进程PID> --seconds 600 --interval 1 --output /path/to/session.json
```

此脚本只读取 PID / PPID 和系统资源计数，输出不保存 PID、路径或媒体字段。利用 Mach 时间基准换算 CPU，并累计已回收子进程与存活后代的 CPU；CPU 100% 表示占满一个逻辑核心。读取并非原子快照；RSS 求和可能重复计入共享内存，短时进程内存峰值可能漏采。未测量 GPU 或电池消耗，也不随 App 运行、不自动上传。固定场景前先等待状态稳定，并注明显示器、减少动态效果设置和采样期间操作。

回退时退出 CloudPlatter，从 [preview.3](https://github.com/Chengyunlai/cloud-platter/releases/tag/v0.1.0-preview.3) 重新安装；新版显示偏好可保留，旧版会忽略这些键。无需修改网易云账号或系统安全设置。
