# CloudPlatter 项目路线图

## 目标

CloudPlatter 的第一个稳定里程碑是：用户在网易云音乐播放歌曲时，桌面上出现与播放状态同步的黑胶场景，并能从 GitHub Releases 安装一个明确标注风险的开源构建。

## Phase 0：工程基线

- 建立可编译、可测试的 Swift 原生菜单栏应用骨架。
- 使用 CI 验证格式、构建、测试和 Universal 应用打包。
- 使用 `v*` 标签创建包含 ZIP 与 SHA-256 的 GitHub Release。
- 建立中文默认文档、贡献规范、Issue 模板、PR 阶段政策和领域文档。

完成标准：`make check` 和 `make package` 在本机及 GitHub Actions 通过。

## Phase 1：播放状态源技术 Spike

状态：核心 Go 条件已通过；未覆盖的内容类型不阻塞 MVP，按真实反馈补充。

- 验证 MediaRemote 在普通 GitHub 自签构建中的读取边界，并记录受限制 entitlement
  的失败方式。
- 验证由系统 `/usr/bin/perl` 加载隔离 MediaRemote helper 的能力、输出协议和失效方式。
- 验证来源、标题、艺人、专辑、封面、播放状态、进度和切歌更新延迟。
- 覆盖播放、暂停、切歌、拖动、客户端重启和休眠唤醒。
- 以普通歌曲和播客覆盖音乐与长音频两类代表性内容；VIP/试听、私人 FM、MV 和本地音乐
  在出现真实兼容问题时按需补充，不作为首版发布门禁。
- 在不记录真实曲名的前提下形成字段兼容表与脱敏 fixtures。
- 首个 `v0.1.0` 以已验证的 Perl 事件流为默认；事件流在真实切歌中返回空快照时，按需启用
  [#11](https://github.com/Chengyunlai/cloud-platter/issues/11) 的网易云定向 JXA 查询，恢复后
  立即停用轮询。

Go 条件：隐藏或最小化网易云音乐时仍能实时取得标题、艺人和播放状态；大多数测试内容
能取得封面；helper 缺失、进程退出和接口异常可以安全降级；默认路径不申请辅助功能或屏幕
录制权限，也不遮挡或抢占用户界面。

## Phase 2：端到端 MVP

- 将播放状态源的原始数据规范化为 Now Playing State。
- 菜单栏和设置窗口展示真实播放状态。
- 建立可移动、缩放、隐藏和鼠标穿透的桌面场景。
- 实现唱片旋转、暂停减速、换歌和唱臂进度动画。
- 增加登录时启动、减少动态效果和窗口显示模式。

完成标准：用户无需再次登录网易云音乐，即可从安装到看到实时桌面黑胶完成完整体验。

## Phase 3：稳定性与首个发布版

- 验证多显示器、Spaces、Stage Manager、全屏和睡眠唤醒。
- 控制静态与播放状态的 CPU/GPU 消耗。
- 完成脱敏诊断、隐私说明、兼容矩阵和安装文档。
- 发布 `v0.1.0`，收集封闭测试反馈；达到稳定标准后再决定是否开放常规外部 PR。

## 暂不进入路线图

- 播放控制、歌词、账号、歌单、收藏和推荐。
- Spotify、Apple Music 或其他播放器适配。
- 社区逆向 API、Cookie 抓取、模拟登录和进程注入。
- Mac App Store、完整 3D 物理渲染和在线遥测。
