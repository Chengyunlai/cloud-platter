# Issue 分诊标签

自动化技能使用五个固定角色。本表把内部角色映射到 CloudPlatter 的中文 GitHub 标签。

| 内部角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待评估` | 等待维护者确认价值、范围和优先级 |
| `needs-info` | `待补充信息` | 等待报告者补充复现、需求或环境信息 |
| `ready-for-agent` | `可由代理处理` | 规格和验收标准完整，可由自动化开发代理独立完成 |
| `ready-for-human` | `需人工处理` | 需要人工设计判断、设备操作、签名凭据或其他现场能力 |
| `wontfix` | `不予处理` | 已决定不进入计划 |

技能提到英文内部角色时，必须使用本表对应的中文标签，不得另建同义标签。
