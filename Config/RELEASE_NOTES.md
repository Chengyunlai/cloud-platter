## 预览版说明

这是 CloudPlatter 的公开预览版，适合体验网易云音乐桌面唱机场景并协助验证兼容性，尚不视为

## 安装提示

这个版本使用 ad-hoc 签名。首次打开时，你可能需要在 macOS“隐私与安全性”设置中手动允许 CloudPlatter；不需要也不建议全局关闭 Gatekeeper。

推荐下载 DMG，并使用同目录的 `.sha256` 文件验证完整性：

```bash
shasum -a 256 -c CloudPlatter-*.dmg.sha256
```

打开 DMG 后，将 `CloudPlatter.app` 拖到“Applications”快捷入口。ZIP 继续作为备用安装包。

## 已知兼容性

CloudPlatter 会启动系统 `/usr/bin/perl` 子进程，并由它加载应用附带的 BSD-3-Clause
MediaRemote Adapter。事件流为空、不可用，或播放时静默超过 4 秒（正常暂停为 15 秒）时，应用会先通过同一隔离边界执行
一次性快照；仍无可展示状态时，再由系统 `/usr/bin/osascript` 按需执行 MIT 许可的网易云定向
JXA 查询，并在事件流恢复后停止轮询。这些路径依赖未公开的 macOS
MediaRemote 行为，系统或网易云音乐升级后可能失效；应用会安全降级，不会要求你关闭系统
安全功能。安装包内包含完整第三方软件声明。本项目通过 GitHub Releases 直接分发，不通过
Mac App Store。

## 播放控制

每块显示器提供上一首、播放/暂停和下一首三个白色半透明桌面按钮。控制条使用独立的小型窗口，
只有按钮区域接收鼠标，不会阻挡其余桌面。每次点击都会先确认系统当前媒体仍来自网易云音乐；
来源变化、接口超时或命令被拒绝时不会控制其他播放器，也不会在反馈中暴露播放内容。

## 桌面视觉

CloudPlatter 使用每块显示器一个全屏、点击穿透的桌面层呈现胡桃木唱机场景。场景位于系统
壁纸之上、桌面图标和普通应用窗口之下，不修改系统壁纸文件。当前封面会同时显示在专辑封套
和唱片中心；低分辨率封面会按屏幕倍率保持原生物理像素，并在封套的独立印刷底板中呈现。播放、暂停、
Reduce Motion、屏幕休眠和会话锁定会控制持续动画。
